# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-05-08

### Added

- Initial release of `live-chat-ui`
- `LiveChat` component for embedding real-time chat in React applications
- Support for Socket.IO-backed messaging
- Headless `useLiveChat` hook for advanced usage
- Dark and light theme presets with custom color overrides
- File/image attachment support
- Message history pagination
- Typing indicators and connection status
- Toast notifications
- Full TypeScript support with exported types
